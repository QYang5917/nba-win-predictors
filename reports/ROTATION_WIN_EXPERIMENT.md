# 分钟预测接入胜率：完整链路实验

2026-11-12。实现：`src/rotation_win_experiment.py`。冻结的日常模型、历史预测和自动脚本均未改动。

## 结论

分钟误差降低没有自动转化为明显的胜率优势。接入学习型期望分钟后，固定替补水平版本的 Log loss 从 0.606116 降至 0.605902，固定策略模拟 ROI 从 -4.07% 到 -3.36%，仍亏损且误差差值区间跨零。未部署研究候选。

## 这轮实际完成的工作

1. 分钟模型从 2018/19 开始逐季生成预测，每季仅在更早赛季拟合。这样后续胜率模型的训练输入也是分钟模型的样本外预测，避免拿分钟训练集上的拟合值伪装成赛前预测。
2. 重新生成 2018/19—2025/26 的历史球员评分，每约 14 天刷新一次，每次只用刷新日前的比赛，箱分权重和年龄曲线只用更早赛季。没有把今天的球员评分套回历史。
3. 候选名单仍只取球队上一场出场球员，不根据本场结果补回真实复出者。超过 240 的预期分钟按比例缩小；不足 240 不强制分满。
4. 比较固定替补水平和显式未分配分钟两个方案。后者用已知球员贡献差、未分配分钟差分别预测胜负，由过去数据估计未分配部分的平均关系，不假装已经知道具体替补是谁。
5. 胜率模型逐季向前训练；市场组合又只使用更早赛季的样本外胜率预测。分钟、评分、胜率、市场组合四层均有时间边界。
6. 增加按输入/代码 SHA-256 隔离的评分缓存，便于复现而不重复计算历史评分。

重新计算的旧实力特征与原项目 `LAST_GAME_STRENGTH_DIFF` 的最大绝对差约 7.1e-15，说明对照组实现与原实力算法一致。

## 同一组 3,209 场比赛上的结果

本轮要求两队都有本季上一场名单，因此排除了赛季开场的相关比赛。与上一轮 3,256 场样本不同，胜率训练也改为从 2018/19 起始，以配合分钟层的时间切分；必须在本轮共同样本上比较，不能直接把本轮数字与上一轮相减当提升。

固定策略沿用：预计收益 >3%，每场最多一边、固定一单位，按提供的十进制收盘赔率结算；没有优化投注门槛。

| 方案 | 命中率 | Log loss ↓ | 投注数 | ROI |
| --- | ---: | ---: | ---: | ---: |
| 原分钟 → 原实力 | 67.19% | 0.606116 | 2,192 | -4.07% |
| 学习期望分钟 → 固定替补水平 | 67.09% | **0.605902** | 2,198 | -3.36% |
| 学习期望分钟 → 单独估计未分配部分 | 67.31% | 0.605986 | 2,164 | -3.35% |
| 原分钟 + 球队近期状态 | 67.19% | **0.603253** | 2,017 | -5.52% |
| 学习分钟 + 未分配部分 + 球队状态 | 67.53% | 0.603564 | 2,025 | -6.14% |
| 去水市场基线 | 68.34% | **0.590196** | 0 | 不适用 |

固定替补版本比原版的 Log loss 差值为 -0.000214，按日期成对 bootstrap 的 95% 区间约 [-0.001420, +0.000935]。区间跨零，不能认定提升可靠。加入球队近期状态后，新分钟模型反而没有胜过旧分钟版本。

## 如实保留的正收益分支

重新训练的旧模型与市场组合在这组样本上触发 39 笔投注，收益 +20.80 单位、ROI +53.33%。这不是新分钟模型带来的提升，也不是稳定盈利的证据：

- 按日期重采样的 95% ROI 区间约为 -21.8% 到 +140.0%，包含亏损。
- 三季分别盈利 +0.25、亏损 -1.25、盈利 +21.80 单位，收益集中在最后一季。
- 该结果与此前 22 笔亏损结果不同，涉及训练样本/评估覆盖变化；市场组合对这些选择很敏感。
- 在多个已经看过的历史方案中发现一个正收益分支，存在选择偏差；没有进行独立新数据验证。
- 收盘赔率缺少可验证采集时间，不能证明能在预测时成交。

其余市场组合结果也完整保留：新固定替补和新未分配版本均 7 笔、-39.29%；原状态组合 4 笔全亏；新状态组合 11 笔全亏。样本过少，均不能作为强结论。没有隐藏失败分支或挑选唯一盈利策略发布。

## 下一步的技术重点

当前分钟模型的主要限制仍是候选名单：上一场名单会遗漏复出、新加入轮换的球员，并包含新受伤或被轮休的人。没有带时间戳的完整伤病与花名册记录，继续微调分钟权重很可能只带来微小变化。下一阶段应将前瞻性阵容快照与真实赔率快照接入并行验证，再测试近期候选池和可学习的出战概率。

回测里未使用本场出场名单填充缺口。未分配分钟模型只是统计代理；它没有解决复出者的身份、出场意愿或交易状态。

历史赛季已反复检查；日期 bootstrap 未覆盖跨日相关性、参数不确定性和多重比较。本轮结果不包含实际交易约束、税或拒单。
