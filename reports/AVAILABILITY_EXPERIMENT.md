# 最近五场候选池与出场概率实验

2026-11-12。代码：`src/availability_experiment.py`。本轮从名单覆盖入手，完整跑过候选池、分钟、球员实力、胜率、市场组合与模拟结算。未修改冻结模型或真实预测日志。

## 实现

- 将候选池从上一场出场者扩展为球队本赛季最近五场出现过的球员。五场是固定研究设定，没有根据收益搜索窗口。
- 每个日期先用过去记录生成全部球队的候选特征，之后才让当日参与者与结果更新状态。不会先看今日出场名单再挑候选人。
- 特征包含最近一次分钟、历史预计分钟、最近五场出勤率（早期按可用场数）、含缺阵零值的平均分钟、连续缺阵场数、距上次出场天数、球队休息天数及名单规模。
- 若某球员在此前日期已被观察到为另一队出场，预测时在旧队设为零。这是根据已观测球队归属的代理，不能替代完整交易和注册记录，也无法识别尚未上场的新交易。
- 固定比较两种方案：直接预测包含缺阵零值的期望分钟；先预测出场概率，再乘以确认出场条件下的期望分钟。
- 出场模型、分钟模型每季只用更早赛季；球员评分每约 14 天用此前比赛重算；胜率与市场组合继续采用分层时间切分。
- 总期望分钟超过 240 时只向下缩小，不把不足部分强制分给已知球员。未分配部分作为单独特征交由历史胜率模型估计。

## 名单与分钟结果

2023/24—2025/26，7,290 个球队比赛样本，实际参与者 78,330 个球员比赛记录：

| 指标 | 上一场候选名单 | 最近五场候选名单 |
| --- | ---: | ---: |
| 覆盖实际出场球员的比例 | 85.63% | **96.52%** |

覆盖率只衡量实际出场者是否在候选池，扩池也会加入没有出场的人，不能把 96.52% 当成出场预测命中率。

在同一份扩大后的评估并集（105,168 行，包含未出场候选人和漏掉的实际参与者）上：

| 分钟方案 | MAE ↓ | RMSE ↓ |
| --- | ---: | ---: |
| 原分钟规则 | **6.2226** | 9.9056 |
| 五场池，直接预测分钟 | 6.2927 | **8.8173** |
| 五场池，出场概率 × 条件分钟 | 6.2940 | **8.8171** |

RMSE 降低约 11.0%，MAE 略变差。说明大误差减少，但不能说所有指标都更好。这份评估并集比上一轮分钟实验更大，不能把这里的 6.22 与旧报告的 7.30 直接比较。

在五场候选池内，“上一场上过就预测一定出场，否则一定不出场”的 Brier 误差为 0.1938，学习的出场概率为 0.1254。此比较对象是较粗的确定性规则；不是与专业伤病预测系统相比。

概率分箱诊断（未另外做校准）：

| 预测出场概率区间 | 样本数 | 平均预测概率 | 实际出场率 |
| --- | ---: | ---: | ---: |
| 0—20% | 2,483 | 15.64% | 12.04% |
| 20—40% | 16,834 | 30.22% | 31.55% |
| 40—60% | 12,364 | 48.13% | 50.76% |
| 60—80% | 6,809 | 70.74% | 71.43% |
| 80—100% | 63,954 | 93.14% | 92.03% |

这些概率来自比赛历史，未读取真实伤病状态或发布时间；不能解释成模型已经理解 Out / Questionable。

## 完整胜率与模拟收益

与上一轮一致的 3,209 场赔率匹配样本；两队都必须有本季此前比赛。固定规则仍为预计收益 >3%、每场最多一笔一单位，未搜索收益门槛。

| 方案 | 命中率 | Log loss ↓ | 投注数 | ROI |
| --- | ---: | ---: | ---: | ---: |
| 原球员模型 | **67.19%** | 0.606116 | 2,192 | -4.07% |
| 五场池直接分钟 | 66.63% | **0.605827** | 2,134 | **-3.14%** |
| 五场池出场概率 × 条件分钟 | 66.72% | 0.605897 | 2,119 | -3.99% |
| 原球员 + 近期球队状态 | **67.19%** | **0.603253** | 2,017 | -5.52% |
| 五场池两阶段 + 近期球队状态 | 66.87% | 0.603660 | 2,049 | -5.82% |
| 去水市场基线 | **68.34%** | **0.590196** | 0 | 不适用 |

直接分钟版本比原版的 Log loss 差为 -0.000290，日期成对 bootstrap 的 95% 区间 [-0.003363, +0.002536]，仍跨零。其 ROI 区间约 [-9.12%, +3.03%]，也不能确认正收益。两阶段方案没有明显优于直接预测，不能仅因更复杂就替换模型。

市场组合全部保留：

| 组合 | 投注数 | ROI |
| --- | ---: | ---: |
| 原球员 + 市场 | 39 | +53.33% |
| 五场直接分钟 + 市场 | 6 | -100.00% |
| 五场两阶段 + 市场 | 6 | -100.00% |
| 原球员/球队状态 + 市场 | 4 | -100.00% |
| 五场两阶段/球队状态 + 市场 | 27 | +12.04% |

最后一项的 ROI 区间约 [-76.1%, +122.5%]。少量投注的正收益不能证明稳定盈利；原组合的正收益亦是前一轮已披露的同一个结果，不是新独立发现。所有亏损分支均写入机器可读报告。

## 验证与后续

新增测试检查复出者能够入池、今日名单变化不能改变今日候选特征、五场窗口淘汰、已观测换队状态、未来标签不进入出场/分钟/胜率训练。连同之前共 22 项测试通过。

五场池改善了短期缺阵后的覆盖，但仍遗漏长期伤停复出、赛季首场、新秀首秀及尚未观测的新交易；预测概率也缺少临场伤病消息。这是下一步引入带时间戳阵容信息的明确理由。新研究候选尚未部署。

这些历史赛季已重复研究，存在研究者选择偏差；按日期重采样未处理跨日期相关性与模型选择不确定性。收盘赔率无可验证采集时间，没有可成交性证明，模拟收益未包括真实交易约束和税。

复现：

```sh
.venv/bin/python src/availability_experiment.py
.venv/bin/python -m unittest discover -s tests -v
```

结果位于 `reports/availability_experiment/`：`summary.json`、`predictions.csv`、`ledger.csv`；缓存保存每名候选人的历史出场概率、条件分钟与实际结果，用于诊断。缓存按输入与代码哈希隔离。
