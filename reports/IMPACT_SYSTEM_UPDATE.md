# 球员评分与胜负预测更新

2026-11-13。本轮完成了高阶数据转换与校验、一个更保守的球员评分对照，以及加入球队状态/赛程的胜负预测实验。尚无明确命中率提升，完整高阶影响力评分仍缺真实数据及历史训练目标。

## 个人评分对照

`rating_experiment.py --impact-control` 固定比较近期归一化版本（贡献正则 30）与贡献正则 120 的版本。名单、分钟、技术统计先验、年龄修正及训练截点相同，目的在于减少对全场比分修正的依赖；不能据此声称已分离队友影响。

共同 3,633 场，训练起点 2018-19，每个目标赛季仅用之前赛季训练胜负模型：

| 版本 | 准确率 | Log loss | Brier |
|---|---:|---:|---:|
| 近期归一化 | 68.18% | 0.593753 | 0.204066 |
| 更强贡献收缩 | 68.13% | 0.596203 | 0.205098 |

更强收缩的概率误差差值为 +0.002450，按日期配对 bootstrap 区间 [0.000274, 0.004563]。本轮结果不支持替换原候选。

## 球队状态对胜负预测的补充

`impact_context_experiment.py` 在评分外加入赛前 Elo、近 10/30 场净效率、背靠背和近七天比赛负荷，参数固定。只用既有逐赛季预测特征可得的 2021-22 起数据训练，与上表训练起点不同，需使用本实验自己的基线比较。

| 版本 | 同一 3,633 场准确率 | Log loss | Brier |
|---|---:|---:|---:|
| 球员评分基线 | 68.26% | 0.594113 | 0.204223 |
| 原评分＋状态/赛程 | 68.15% | 0.592389 | 0.203535 |
| 更强收缩＋状态/赛程 | 68.15% | 0.593087 | 0.203740 |

原评分＋状态/赛程在三个赛季的 Log loss 均降低，但准确率并非每季提高。总体 Log loss 差值 -0.001724，按日期配对 bootstrap 区间 [-0.004181, 0.000888]，跨零。将其保留为研究候选，未替换正式模型。

所有历史区间都已反复研究，并非未见前瞻测试；日期 bootstrap 未覆盖跨日期依赖、训练不确定性或模型选择。这里没有新盈利结论。

## 高阶数据接入的实际状态

上一轮只接入了规范化表的评分接口，尚不能直接读取下载后的 NBA 表。本轮新增 `normalize_impact_inputs.py`：

- 显式要求每 36 分钟的基础与 Misc 输入，避免把赛季累计内线得分、失误后得分与效率指标混在一起。
- 使用 NBA 个人防守端点的 `CLOSE_DEF_PERSON_ID` 对齐球员。
- 分别处理三分及六英尺内追踪防守，计算被防守命中率相对射手基准的差；保留防守出手次数。六英尺内不等于整个禁区。
- 零防守出手、缺失球员保留为空；重复球员、来源不完整、未知单位直接报错。
- 使用各来源获取完成时间中的最晚时间作为快照时间；赛季累计快照不能用于回填同季过去比赛。
- 高阶评分接口拒绝未来快照、错误比例单位、未来训练目标；不完整球员的 `ADVANCED_IMPACT` 为空。

重新调用 NBA 接口仍发生 `NameResolutionError`，失败清单已存入 `data/raw/player_impact/20261114T062516933403Z/manifest.json`。未产生真实的完整高阶输入、历史前瞻目标或训练后的高阶影响力模型，因此也没有产生完整高阶排名。新转换器目前通过合成响应结构测试，实际服务字段或口径变化仍需校验。

当前采集器没有在场/离场及五人阵容数据，不能声称这些内容已接入。NBA 的在场攻防效率是球员在场时的球队表现，作为上下文使用，不能直接当个人攻防贡献。
