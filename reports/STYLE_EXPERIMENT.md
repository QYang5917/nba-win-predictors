# 用户指定的得分、篮板与防守指标实验

使用球队过去 20 场（至少 10 场）的统计，先移除当场数据，再合计分子分母计算比率。跨赛季保留历史窗口，不读取赛季未来数据。三分得分转换为每百估算回合得分；篮板拆为进攻篮板率和防守篮板率；对手三分命中率按总命中/总出手计算。所有指标为主客队之差。

数据可支持这三类指标。内线得分、失误后得分、对手内线命中率没有逐场输入，尚未测试。赛季汇总的投篮区域表不能用来预测同季比赛；两分球不等于内线得分，抢断不等于失误后得分。

保持近期加权且归一化的球员实力差与休息天数差为基线。各赛季只在更早赛季训练，训练数据从 2021-22 开始，评估 2023-24 至 2025-26 的相同 3,633 场。由于训练起点不同，本报告基线与前一份球员评分实验的数值不可直接比较。

| 加入指标 | 准确率 | Log loss，越低越好 |
|---|---:|---:|
| 仅球员基线 | 68.26% | 0.594113 |
| 三分得分 | 67.99% | 0.594520 |
| 进攻/防守篮板率 | 68.32% | 0.594153 |
| 对手三分命中率 | 68.46% | 0.593804 |
| 全部可用指标 | 68.13% | 0.594281 |

没有人为指定更大系数，而是让标准化逻辑回归在训练期学习权重，使用固定 C=1。简单放大输入后再标准化不会增加模型对该特征的重视。

对手三分命中率的结果最有希望，但相对基线的 Log loss 差仅 -0.000309，按日期配对 bootstrap 95% 区间 [-0.000802, 0.000168]，跨零。所有新增版本的误差差值区间都跨零。不能把本轮最好结果称为已证实改善，尤其这是多项比较且历史评估区间已反复使用。日期 bootstrap 也未处理跨日期依赖与调参选择不确定性。

这些是球队风格特征，不是球员个人防守评分。对手三分命中率尚未控制对手射手水平、投篮位置和干扰程度，不能直接据此给某个球员加减分。当前检验只覆盖一种 20 场窗口的线性增量模型，不能据此认定指标永远无用。

下一步数据需求：逐场 points in paint、points off turnovers，以及双方禁区出手/命中。建议把内线定义明确为禁区得分，并区分篮下 restricted area 与其他禁区；按回合或机会数标准化，再评估对手强弱和进攻/防守对位交互。个人评分进一步需要球员在场阵容与回合归因，避免把全队数据直接分摊。

复现：`.venv/bin/python src/style_experiment.py`。明细在 `reports/style_experiment/summary.json` 和 `predictions.csv`；未替换线上模型、修改球员生产评分或下注。
