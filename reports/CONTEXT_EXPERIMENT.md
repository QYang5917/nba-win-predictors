# 模型提升实验：球员实力 + 近期状态 + 赛程

2026-11-12。新代码 `src/context_experiment.py`，保持冻结实盘模型不变。

## 研究假设和设计

球员评分难以及时捕捉球队近期磨合、打法和状态变化，因此加入球队动态信息可能改善概率预测。固定三个实验组：上场名单球员模型、球队状态模型、两者结合。全部采用带标准化的逻辑回归，不在本次评估集搜索参数。

新增特征为赛前 Elo、最近约 10/30 场的指数加权净效率、背靠背、过去七天比赛数量，全部取主队减客队。Elo K=20，主场偏置=65；每个赛季开始将 Elo 相对平均值和净效率乘 0.75；这是研究假设，不是已验证的最佳参数。净效率采用双方估计回合数平均值作为分母，不单独把回合数多当成球队强。

每个日期开始时先冻结全部球队状态，再生成当天比赛特征，最后才更新结果。没有使用本场赛后实际参与者，也没有使用旧团队特征生成器中的全历史联盟均值回填。球员和休息差特征仍复用现有文件。

每个赛季模型只在之前赛季拟合；再用过去赛季的样本外概率拟合市场组合模型。所有方案在同样的精确日期赔率匹配样本上比较。比赛名单、策略、赛季划分都不是新的未触碰测试集，不能把这次研究当成独立验证。

## 实际结果

共同评估样本 3,256 场，2023/24—2025/26；最后一个赛季赔率只有部分覆盖。

| 版本 | 命中率 | Log loss ↓ | Brier ↓ | 固定规则投注数 | ROI |
| --- | ---: | ---: | ---: | ---: | ---: |
| 球员 | 67.11% | 0.608069 | 0.210253 | 2,229 | -4.99% |
| 球队状态 | 65.79% | 0.613976 | 0.212995 | 2,244 | -7.86% |
| 球员 + 状态 | 67.05% | **0.604500** | **0.208704** | 2,033 | -5.12% |
| 去水市场基线 | 68.37% | **0.590137** | **0.202670** | 0 | 不适用 |

固定投注规则沿用前一轮：期望收益 >3%，每场最多一笔一单位；不搜索阈值。ROI 不包含税、拒单或账户限制等实际执行条件。

新版本的概率误差下降约 0.59%，命中率略降，ROI 略差。模型输出 60%、70% 等概率的质量改善，与能否盈利是不同问题。三季的 Log loss 均有改善：

| 赛季 | 球员模型 | 球员 + 状态 |
| --- | ---: | ---: |
| 2023/24 | 0.601510 | 0.598031 |
| 2024/25 | 0.599821 | 0.594779 |
| 2025/26（部分） | 0.630718 | 0.629258 |

按日期成组、成对 bootstrap 的 Log loss 差值（新版减旧版）为 -0.003569，95% 区间 [-0.006122, -0.000811]。这支持继续研究，不能覆盖反复查看历史样本的选择偏差，也不包含跨日期依赖和重新训练的不确定性。

将新版与市场组合后，Log loss 为 0.590240，略差于原始市场；差值的区间跨零。只触发 3 笔模拟投注，均亏损。未发现可靠的市场外信息优势，不替换现有市场组合版本或冻结模型。所有方案包括失败方案均保存在 `context_experiment/summary.json`。

## 数据问题

10 场原始记录没有一主一客的明确标记（两条都带 `@`），已在状态构建前整体排除；完整 ID 记录在 JSON。它们也没有可用的原球员强度特征。本轮不凭结果猜测主客队，不改写原始数据。中立场与常规主场仍未单独建模。

## 后续优先级

1. **预计阵容与分钟分布**：用可验证发布时间的伤病信息，建模出战概率、限制时间、替补分配；当前“上场打过的人下一场继续打”代理会漏掉新伤病与复出。通过回测才能确认增益。
2. **预测时点的赔率快照**：记录模型与可成交报价的同一 UTC 截止时间，区分模型预测好与实际价格有利。当前收盘文件没有报价采集时间。
3. **近期状态模型作为并行候选**：在新的未来比赛上与冻结版本同时留档，预先固定评估方法，不因几次输赢改权重。
4. **有数据后再测试阵容交互和非线性**：先做少量明确假设的对照实验；增加复杂度本身不保证提高样本外表现。
